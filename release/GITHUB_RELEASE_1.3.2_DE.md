# WP Restatify Booking Assistant 1.3.2

## Was ist neu

- LightStart-Integration fuer Wartungsmodus hinzugefuegt
- Neue Option: `Bei LightStart-Wartung ausblenden` (Standard: AN)
- Option nur sichtbar, wenn LightStart installiert und aktiv ist
- Overlay-Unterdrueckung greift fuer Assets, Shortcode und globales Popup

## Warum

Bei aktiver Wartungsseite sollen Buchungsdialoge optional nicht eingeblendet werden, damit Besucher nur die gewollten Wartungsinhalte sehen.

## Kompatibilitaet

- Keine Breaking Changes in vorhandenen Optionen
- Single-Site und Multisite (Netzwerkaktivierung) werden unterstuetzt
