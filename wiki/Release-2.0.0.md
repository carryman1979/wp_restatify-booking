# Release 2.0.0

Version 2.0.0 konsolidiert Branding/Slugging und bringt den Booking-Assistant auf den neuen Release-Stand fuer das 2.x-Linienmodell.

## Highlights

- Plugin-Slug/Ordner auf `wp_restatify_booking` vereinheitlicht
- Plugin-Version auf `2.0.0` angehoben
- Dokumentation und Release-Artefakte auf das neue Naming ausgerichtet

## Technische Einordnung

Das Release ist bewusst stabilitaetsorientiert: keine funktionalen Brueche in der Buchungslogik, aber klare Vereinheitlichung der Paket- und Plugin-Namen fuer Betrieb und Deployment.

## Validierung

- API-Authentifizierung mit produktivem Key erneut validiert
- Terminbuchung erfolgreich angelegt
- Oeffentlicher Storno-Flow erfolgreich durchlaufen
- Bestaetigungs- und Stornomail in Mailpit verifiziert

## Kompatibilitaet

- Plugin-Version: `2.0.0`
- API kompatibel mit dem aktuellen Booking-API-Stand
- Keine erforderlichen manuellen Datenmigrationen

## Artefakt

- `wp_restatify-booking-2.0.0.zip`
